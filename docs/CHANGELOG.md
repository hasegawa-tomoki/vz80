# 変更履歴

## 1.0.0 (2026-10-01) 最初の配布版（基板 V1.0 / V2.0 共通ファーム）

- 動作速度: MSX 等速、MSXturboR 相当、Max。
- メモリマッパの拡張（最大 1 MB）。
- 仮想カートリッジ: SD カードの ROM を内蔵スロットに挿したように見せる（同時に 4 本まで、MegaROM のマッパは自動判別）。
- 仮想 FDD / 仮想 HDD: 内蔵ドライブの置き換えと、Nextor 用の vz80 ディスクドライバ（`release/msx/nextor-vz80-1.0.0.zip`）。
- Web UI: 画面表示、キー送信、SD カードブラウザとテキスト編集、ドライブ設定、スロット、ファームウェア更新。
- ファームウェア更新: Web UI、SD カードの `vz80-X.Y.Z.vzp` による自動更新、USB。失敗時は元の版に戻る。
- Wi-Fi の送信出力の設定（`txpower`、MSX の電源が細い環境での画面の暗転対策）。
- 基板 V2.0 対応: ESP32 との SPI リンク、基板の自動判別、ESP32 駆動の LED、音声 PWM、MSX リセット。
