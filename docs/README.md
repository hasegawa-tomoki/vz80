# VZ80

MSX 用 多機能 Z80 アクセラレータ

## 概要

MSX 用の多機能 Z80 アクセラレータです。  
MSX 本体から Z80 を取り外し、Z80 のかわりに装着して使用します。RP2350B が Z80 をエミュレーションして実機のバスを駆動し、ESP32-C3 が Wi-Fi と microSD を担当します。

### システム要件

* MSX2+ Sony HB-F1XDJ
    * 現在は HB-F1XDJ のみで動作確認しています。
    * Z80 が DIP 40 ピンのソケットに載っている MSX なら物理的には装着できます。仮想フロッピーの「内蔵ドライブ」機能は FDC の配線が Sony / Philips 方式の機種向けで、それ以外の機種では Nextor 経由の仮想ドライブのみ使えます。
    * メインメモリ・VRAM は実機のものをそのまま使います。
* microSD カード（FAT32）
    * ディスクイメージ・ROM イメージ・Wi-Fi 設定を置きます。
* 2.4 GHz の Wi-Fi（任意）
    * Web UI を使うために必要です。なくても MSX は動作します。
* 電源は MSX の 5 V を使います。外部電源は不要です。

### 基板バージョン

* V1.0: 初版（RP2350B + ESP32-C3-WROOM-02 + 64 MB フラッシュ + 8 MB PSRAM、4 層）
* V2.0（設計中、未頒布）: RP2350 と ESP32 の間を UART から SPI に変えて SD カードの転送を高速化し、音声出力（SCC / MSX-Audio のエミュレーション用、カートリッジスロットの SOUNDIN へ接続）と MSX の /RESET 駆動を追加したバージョン

### 機能

#### CPU 機能

Z80 の全命令を RP2350B（150 MHz）でエミュレーションし、実機のメモリ・VDP・PSG・FDC には実バスでアクセスします。

* 実機の 3.58 MHz 相当（MSX2）、turboR 相当（約 5.4 倍）、制限なし（約 9 倍）を Web UI から切り替えられます
* メインメモリ（メモリマッパ）を 64 / 256 / 512 / 1024 KB に拡張できます（64 KB 超は基板の PSRAM。MSX-DOS 2 / Nextor の DOS 2 モードに必要な 128 KB 以上が取れます）
* 仮想 ROM カートリッジ: SD カードの ROM イメージ（プレーン、ASCII 8K / 16K、コナミ、コナミ SCC）を任意のスロット・ページにマウントできます。同時に 4 本まで。マッパは自動判別（実行時に確定）
* 仮想フロッピー: 内蔵ディスク ROM の FDC（WD2793）を横取りし、ドライブ A / B を内蔵（物理）・仮想・なしに切り替えられます。仮想ドライブには SD カードの 2DD / 1DD イメージをマウントし、書き込みは SD カードに書き戻されます
* Nextor: vz80 用ドライバを組み込んだ Nextor ROM を挿すと、仮想 FDD（2DD イメージ）と仮想 HDD（FAT16 イメージ、48 MB まで）をドライブとして使えます。DOS 1 モード（DOS1 形式のディスクから起動）と DOS 2 モードの両方に対応
* USB コンソール: RP2350 の USB から状態の確認、設定、デバッグができます（`tools/console`）

#### Web UI 機能

ESP32 を Wi-Fi に接続すると Web UI が使えます。

* CPU 速度、VDP アクセス間隔、RP2350 クロック、メインメモリ容量の設定
* ドライブ設定（内蔵 / 仮想 / なし、Nextor のドライブの追加・削除・並べ替え）とスロットカード（実機のスロット×ページの状態と仮想 ROM のマウント）
* MSX の画面を Web UI に表示・PNG で保存（512 ドットモードは縦 2 倍でも保存可能）
* MSX にキーを送信
* SD カードのブラウザ（アップロード、フォルダ作成、移動、削除、テキストの表示・編集）、空のディスクイメージ作成（DOS1 / DOS2 の 2DD、HDD 16〜48 MB）、HDD イメージのサイズ変更、FAT12 イメージの中身の閲覧・編集
* フラッシュキャッシュの管理（マウントしたイメージは基板のフラッシュに取り込まれ、そこから動きます）
* ファームウェアの更新（パッケージファイルの適用、お試し起動と確定・巻き戻し）
* 同じ LAN にある vz80 / vfd68 / vhd68 / vmpu68 の一覧表示
* macOS の Safari と Chrome で動作確認しています

## セットアップ

### ソフトウェアセットアップ

#### ファームウェアの書き込み（初回のみ）

基板の RP2350 と ESP32-C3 は出荷時に空です。USB ケーブルで Mac / PC につないで書き込みます。

1. RP2350: BOOT（SW1）を押しながら USB を挿すと「RP2350」ドライブが現れます。`picotool load -v vz80.uf2 && picotool reboot` で書き込みます（`vz80.uf2` はビルド成果物か、パッケージ `vz80-x.y.z.vzp` から取り出したもの）。
2. ESP32-C3: RP2350 が起動したら `python3 tools/flash/espflash.py firmware/esp32c3/build` で、RP2350 経由で書き込みます（詳細は `tools/flash/README.md`）。

2 回目以降の更新は Web UI か SD カード経由で行い、USB は不要です。

#### microSD カードの準備

FAT32 でフォーマットした microSD カードのルートに、次のファイルとフォルダを置きます。

* `vz80.cfg` — Wi-Fi 設定（次項）
* `vz80/nextor-vz80.rom` — Nextor を使う場合（`tools/nextor/README.md` の手順で各自ビルド）
* ディスクイメージ（`.dsk`）、HDD イメージ（`.hdd`）、ROM イメージ（`.rom`）は任意のフォルダに

#### 設定ファイルの編集

##### vz80.cfg

Wi-Fi の設定を記述するファイルです。書式は 1 行 1 項目の `key=value` で、`#` で始まる行と未知の行は無視されます。

| 項目 | 値 | 説明 |
|---|---|---|
| `ssid=` | 文字列 | 接続する Wi-Fi の SSID（2.4 GHz） |
| `pass=` | 文字列 | Wi-Fi のパスワード |
| `name=` | 文字列（31 バイトまで） | 表示名。Web UI のヘッダと、LAN 内の他機器の一覧に表示されます。省略可 |

カードを挿した時点で読み込まれ、設定は基板にも保存されるので、その後カードを抜いても接続は保たれます。Web UI の「SD カード」から `vz80.cfg` を編集して保存すると、すぐに接続し直します。

Wi-Fi につながらないとき（設定なし、または 20 秒以内に接続できないとき）は設定用のアクセスポイント `vz80-XXXX`（パスワード `vz80setup`）が立ち上がるので、そこから `http://192.168.4.1/` を開いてカードの `vz80.cfg` を直せます。

### ハードウェアセットアップ

VZ80 は 1 枚の基板です。Z80 の DIP 40 ピンソケットに挿す丸ピンヘッダ（P1 / P2）、RP2350B、ESP32-C3-WROOM-02、microSD スロット、USB Type-C（開発・書き込み用）、BOOT ボタン（SW1）、ステータス LED が載っています。

#### 組み立て

組み立ては不要です。Wi-Fi のアンテナ（ESP32 モジュールの端）が金属に覆われない向きに注意してください。

#### 取付

これ以降は MSX の電源を切って AC プラグも外した状態で作業してください。

1. MSX を分解してメイン基板の Z80 に到達します。HB-F1XDJ は上ケースとシールドを外すとメイン基板が見えます。
2. Z80 を IC ソケットから取り外します。専用の器具を使うか、マイナスドライバーでゆっくり慎重に外してください。Z80 が直付けの機体は、取り外してソケットを取り付ける改造が必要です。
3. Z80 が付いていた IC ソケットに VZ80 を装着します。切り欠き（ピン 1）の向きを Z80 と合わせ、上や横からズレがないように確認しながら、ゆっくり確実に押し込みます。
4. microSD カードを VZ80 のスロットに挿します。

USB ケーブルは MSX に装着したままでも接続できます（書き込みやコンソールに使うとき）。

#### 起動

取り付けが完了したら AC プラグやディスプレイをつないで MSX の電源を入れます。VZ80 は電源投入で自動的に Z80 のエミュレーションを始め、MSX は通常どおり起動します。

Wi-Fi 設定がされていれば LED が青の点滅になり、接続完了で青の点灯に変わります。Wi-Fi 設定がない場合や接続できなかった場合は緑の点灯です。

`tools/lan-finder/lan-finder.html` を開いて [スキャン開始] を押すと同一 LAN 内の VZ80 を検索できます。検出されたら [Web UI] で VZ80 の Web UI を開けます。

## 仕様

### LED 仕様

基板上の LED は以下の状況で点灯 / 点滅します。上の行ほど優先して表示されます。

| 表示 | 意味 |
|---|---|
| 白の速い点滅 | Web UI で「この機器を探す」を押した時（10 秒間） |
| 白の点灯 | 起動中（ファームウェアの初期化からエミュレーション開始までの間） |
| 赤の点灯（一瞬） | ディスク・フラッシュへの書き込み中 |
| 赤の点灯（続く） | PSRAM が見つからない（基板の異常）、または SD カードからのファームウェア更新の取り込み中 |
| 青の点滅 | Wi-Fi 接続中。60 秒たっても接続できなければ緑に変わる |
| 青の点灯 | 正常稼働中（Wi-Fi 接続済） |
| 緑の点灯 | 正常稼働中（Wi-Fi 接続なし）。`vz80.cfg` がないか、60 秒たっても Wi-Fi 接続できない時、または ESP32 から 30 秒応答がない時 |

コンソールの `led R G B` で色を固定、`led auto` で戻せます。

### ファームウェアの更新

3 通りあります。どれも RP2350 は「お試し起動」で入り、20 秒問題なく動けば自動で確定、起動に失敗すれば前の版に戻ります。ESP32 も同様に巻き戻し可能です。

* Web UI の「ファームウェア」で `vz80-x.y.z.vzp` を選んで適用
* `python3 tools/ota/vz80ota.py <ip> pkg vz80-x.y.z.vzp`
* SD カードのルートに `vz80-x.y.z.vzp` を置く（動作中より新しい版なら、マウント直後か 30 秒以内に自動で適用。取り込み中は LED が赤）

RP2350 を更新すると MSX は BIOS から起動し直します。
