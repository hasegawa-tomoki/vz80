VZ80 1.0.0 — 最初の配布版（ボード V1.0 / V2.0 共通ファーム）

## 添付ファイル
- `vz80-1.0.0.vzp`
  - ファームウェアパッケージ。
  - Web UI の「ファームウェア」から適用するか、microSD カードのルートに置くと、ボードのファームウェアバージョンがこれより古いときに更新されます。更新中はLEDが赤く光ります。
- `nextor-vz80-1.0.0.zip`
  - Nextor 2.1.2のカーネルにVZ80の仮想ドライブ用ドライバを組み込んだROMです。
  - `nextor-vz80.rom` をSDカードに置き、Web UIから空きスロットにマウントすると、再起動後にNextorが起動し、Web UIのドライブ設定で仮想FDD/仮想HDDが使える様になります。

## 主な内容
- 仮想カートリッジ
  - ROM を内蔵スロットに挿したように見せる
- 仮想FDD / 仮想HDD
  - Nextor
- メモリマッパ拡張
  - 最大1MB
- 高速動作
  - MSX等速, MSXturboR相当, Max
- Web UI
  - 画面表示, キー送信, SDカードのブラウザとテキスト編集, ドライブ設定, ファームウェア更新
- ボードV1.0, V2.0両対応
